# 数据库设计

脚本：`db/init.sql`（MySQL 8，库名 `campus_activity`，字符集 `utf8mb4 / utf8mb4_general_ci`）。8 张表，字典表独立，满足第三范式；唯一冗余是 `t_activity.signed_count`，在报名事务内维护。

导入命令必须带客户端编码，否则中文学院名会报 `ERROR 1366`：

```bash
mysql --default-character-set=utf8mb4 -uroot -p < db/init.sql
```

## 表关系

```
t_admin ──(created_by)──> t_activity <──(activity_id)── t_attachment
                              │
        t_activity_type ─(type_code)┘
                              │
                              ├──(activity_id)── t_registration ──(college_code)──> t_college
                              │                        │
                              │                        └──(reg_id)── t_checkin
                              └──(activity_id)── t_checkin
t_admin ──(admin_id)──> t_operation_log
```

## 1. `t_admin` 管理员

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `admin_id` | BIGINT PK AUTO_INCREMENT | 主键 |
| `username` | VARCHAR(50) UNIQUE | 登录账号，`uk_admin_username` |
| `password_hash` | VARCHAR(100) | BCrypt 密文，禁止明文 |
| `real_name` / `dept` | VARCHAR | 姓名、部门 |
| `role_code` | VARCHAR(20) | `ADMIN` / `SUPER` |
| `status` | TINYINT | 1 启用，0 停用 |
| `last_login_time` / `create_time` | DATETIME | 时间戳 |

默认超管 `admin / admin123` 不写在 SQL 里，由 `DataInitializer` 在 `t_admin` 为空时用 BCrypt 写入。

## 2. `t_activity_type` 活动类型字典

`type_code` PK、`type_name`、`sort_order`、`enabled`。初始化 5 类：`LECTURE` 讲座、`SEMINAR` 宣讲会、`CAREER` 就业指导会、`TRAINING` 培训、`OTHER` 其他。独立成表是为了消除「活动 → 类型名」的传递依赖。

## 3. `t_activity` 活动

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `activity_id` | BIGINT PK | 主键 |
| `activity_no` | VARCHAR(32) UNIQUE | 业务可见编号 |
| `signup_guid` | VARCHAR(32) UNIQUE | 报名链接随机串，二维码用 |
| `title` / `type_code` / `introduction` | — | 名称、类型（关联字典）、简介 |
| `location` / `lng_lat` | VARCHAR | 地点；`lng_lat` 格式 `lng,lat`，准确签到围栏用 |
| `start_time` / `end_time` / `signup_deadline` | DATETIME NOT NULL | 截止时间必须早于开始时间 |
| `quota` / `signed_count` | INT | 名额上限 / 已报名数（受控冗余） |
| `status` | VARCHAR(20) | 六态：`DRAFT` / `OPEN` / `CLOSED` / `ONGOING` / `FINISHED` / `CANCELED` |
| `checkin_enabled` / `checkin_secret` / `checkin_radius` | — | 签到开关、TOTP 密钥、围栏半径（默认 500 米） |
| `live_url` / `cover_url` / `publish_time` | — | 直播、封面、发布时间 |
| `created_by` | BIGINT NOT NULL | 创建人 `admin_id`，要求拦截器已生效 |
| `create_time` / `update_time` / `deleted` | — | 时间戳与逻辑删除 |

索引：`uk_activity_no`、`uk_signup_guid`、`idx_activity_status`、`idx_activity_type`、`idx_activity_start`。

## 4. `t_attachment` 活动附件

`att_id` PK、`activity_id`（`idx_att_activity`）、`file_name`、`file_url`、`file_size`、`upload_time`、`deleted`。文件本体落在 `campus.file.upload-dir` 指定的磁盘目录，表里只存地址。

## 5. `t_college` 学院字典

`college_code` PK、`college_name`、`sort_order`。初始化 7 项：CS 计算机科学与技术学院、SE 软件学院、EE 电子工程学院、ME 机电工程学院、BIZ 经济与管理学院、ART 人文学院、OTHER 其他。

## 6. `t_registration` 报名记录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `reg_id` | BIGINT PK | 主键 |
| `activity_id` | BIGINT | 关联活动，`idx_reg_activity` |
| `name` / `phone` | VARCHAR | 姓名、手机号 |
| `college_code` | VARCHAR(20) | 关联学院字典，`idx_reg_college` |
| `source_channel` | VARCHAR(20) | `SCAN` / `LINK` |
| `signup_time` | DATETIME | 报名时间 |
| `status` | VARCHAR(20) | `VALID` / `CANCELED` |
| `deleted` | TINYINT | 逻辑删除 |

`UNIQUE KEY uk_activity_phone (activity_id, phone)` 是防重复报名的最终防线；配合服务层预判与 `selectForUpdate` 行锁，保证名额不超卖。

## 7. `t_checkin` 签到记录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `checkin_id` | BIGINT PK | 主键 |
| `reg_id` | BIGINT UNIQUE | 对应报名记录，`uk_checkin_reg` 保证一人一次 |
| `activity_id` | BIGINT | 冗余便于按活动统计，`idx_checkin_activity` |
| `checkin_time` | DATETIME | `idx_checkin_time` |
| `method` | VARCHAR(20) | `BASIC` 基本 / `ACCURATE` 准确 |
| `lng_lat` / `device_fingerprint` | VARCHAR | 坐标与设备指纹，防代签 |

## 8. `t_operation_log` 操作日志

`log_id` PK、`admin_id`、`op_type`、`target_id`、`op_detail`、`ip`、`op_time`，索引 `idx_log_admin`、`idx_log_time`。当前版本主要记录关键操作，未提供后台查询页。

## 约束与约定

- 所有业务表用 `deleted` 逻辑删除，MyBatis-Plus 全局配置 `logic-delete-value: 1` / `logic-not-delete-value: 0`。
- 时间统一 `DATETIME`，前后端传输格式 `yyyy-MM-dd HH:mm:ss`；`ActivityController.parseTime` 同时兼容 ISO 的 `T` 分隔格式与 `datetime-local` 的 16 位格式。
- 统计 SQL 用到 `DATE_FORMAT` 分组，MySQL 8 的 `ONLY_FULL_GROUP_BY` 需要关闭或让分组表达式与 SELECT 一致（仓库里两者都做了）。
- 切换国产数据库：SQL 无方言，只需换驱动与 `MybatisPlusConfig` 的 `DbType`。
