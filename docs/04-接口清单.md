# 接口清单（39 个）

## 平台与组织（新增5个）

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/admin/organizations` | 登录 | 当前账号可选的启用组织 |
| GET | `/api/v1/super/organizations` | 超管 | 全部组织及状态 |
| POST | `/api/v1/super/organizations` | 超管 | 新建组织，传 code 和 name |
| PUT | `/api/v1/super/organizations/{id}/status` | 超管 | 启停组织并撤销组织管理员的旧令牌 |
| GET | `/api/v1/super/audit-logs` | 超管 | 操作审计分页，支持 opType |

管理员和活动均增加 orgId。普通管理员仅能创建、管理和统计所属组织活动；跨组织详情、导出、签到配置及动态码访问返回403。超管可选择组织创建活动；活动创建后不可转移组织。公开活动不限制学生组织归属，但所属组织停用后宣传、报名和签到会关闭。

统一响应结构 `{ code, message, data }`，`code=0` 表示成功。表中路径是**对外路径**，带 `/api/v1` 前缀；Vite 代理或 Nginx 会剥掉前缀后转发到后端，后端自身以根路径部署。

鉴权说明：`公开` 不校验 token；`登录` 需 `Authorization: Bearer <token>`；`超管` 还需 `role_code=SUPER`。导出接口是浏览器直链，无法带 Header，token 走 `?token=` query 参数（`LoginInterceptor.resolveToken` 已支持）。

## 活动审批（新增5个接口）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | /admin/activity/{id}/submit-review | 本组织活动提交审核；仅草稿；重复提交拒绝 |
| GET | /admin/activity/{id}/reviews | 本组织活动审批历史 |
| GET | /admin/reviews | 审批分页；current、size（1至100）、decision；普通管理员仅本组织 |
| PUT | /super/reviews/{id}/decision | 平台审批；decision 为 APPROVED / REJECTED，驳回需 comment，最长500字；不能自审 |
| PUT | /super/organizations/{id}/review-policy | requireReview 布尔值，配置审核后发布或直接发布 |

提交与审批在事务中锁定活动，审批额外锁定申请，保证并发请求仅一次有效。审批通过不会自动发布，仍由活动负责人发布；改稿使通过状态失效。取消活动会关闭待审申请，历史审批记录保留。
