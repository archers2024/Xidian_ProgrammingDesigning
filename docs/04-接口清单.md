# 接口清单（27 个）

统一响应结构 `{ code, message, data }`，`code=0` 表示成功。表中路径是**对外路径**，带 `/api/v1` 前缀；Vite 代理或 Nginx 会剥掉前缀后转发到后端，后端自身以根路径部署。

鉴权说明：`公开` 不校验 token；`登录` 需 `Authorization: Bearer <token>`；`超管` 还需 `role_code=SUPER`。导出接口是浏览器直链，无法带 Header，token 走 `?token=` query 参数（`LoginInterceptor.resolveToken` 已支持）。

## 认证与账号（8 个）

| 方法 | 路径 | 鉴权 | 说明 | 前端调用 |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/auth/login` | 公开 | 账号密码登录，返回 JWT | `authApi.login` |
| POST | `/api/v1/auth/logout` | 公开 | 退出（无状态，前端丢弃 token） | `authApi.logout` |
| GET | `/api/v1/admin/current` | 登录 | 当前管理员信息与角色 | `authApi.current` |
| GET | `/api/v1/super/admin/accounts` | 超管 | 管理员列表 | `adminApi.list` |
| POST | `/api/v1/super/admin/accounts` | 超管 | 新建管理员 | `adminApi.create` |
| PUT | `/api/v1/super/admin/accounts/{id}/status` | 超管 | 启用 / 停用 | `adminApi.status` |
| PUT | `/api/v1/super/admin/accounts/{id}/password` | 超管 | 重置密码 | `adminApi.resetPwd` |
| POST | `/api/v1/file/upload` | 公开* | 上传封面 / 附件，返回 URL | `fileApi.upload` |

\* 当前拦截器只按 `/admin/`、`/super/` 前缀判断，`/file/**` 实际未纳入鉴权。这是现实现的边界，若要收紧，把 `/file/` 加入 `LoginInterceptor` 的 `needLogin` 判断即可。

## 对应关系速查

- 前端接口封装全在 `frontend/src/api/index.js`，axios 实例在 `frontend/src/api/request.js`。
- 后端控制器在 `backend/src/main/java/com/campus/activity/module/*/controller/`。
- 冒烟脚本 `deploy/smoke-test.sh` 覆盖了登录、字典、活动、报名、签到、导出的关键路径。
