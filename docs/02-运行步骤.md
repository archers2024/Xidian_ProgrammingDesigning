# 运行步骤（本机 Windows，逐步照做版）

适用系统：Windows 10/11。Linux/macOS 只需把 `.cmd`、路径分隔符和 MySQL 服务名换掉，命令本身一致。目标是把 `3306 / 8080 / 5173` 三个服务都跑起来，然后在浏览器里走完「建活动 → 报名 → 签到 → 统计」主链路。

## 0. 先确认这四件事

| 检查项 | 命令 | 期望 |
| --- | --- | --- |
| JDK 17+ | `java -version` | 输出版本号，17 及以上 |
| Maven | `mvn -v` | 有版本信息 |
| Node 18+ | `node -v` / `npm -v` | 推荐 Node 20 |
| MySQL 8 | `mysql --version` | 8.0.x |

工程根目录记作 `<ROOT>`，本机是 `D:\Users\15464\Desktop\AI工作区\WorkBuddy\activity-system`。下面所有命令都在这个目录下执行，除非特别说明。

三个端口必须空闲：

```bash
netstat -ano | findstr ":3306 :8080 :5173"
```

如果 8080 或 5173 已被占用，先关掉占用进程，或改端口（改端口要同步改 `frontend/vite.config.js` 的 proxy target 和 `application.yml` 的 `server.port`）。

## 1. 启动数据库

### 1.1 启动 MySQL 服务

管理员身份打开 PowerShell：

```powershell
net start MySQL80        # 服务名以实际安装为准，可能是 MySQL / MySQL80 / MySQL57
```

或者用「服务」`services.msc` 找到 MySQL 启动。验证：

```bash
mysql -uroot -p -e "SELECT VERSION();"
```

提示输入密码时输入本机 root 密码。**仓库里的脚本不写死密码**：设置环境变量 `DB_PASSWORD` 后再运行，脚本会读它。

### 1.2 如果忘了密码或连不上

先确认服务在跑，再确认账号密码。`Access denied for user 'root'@'localhost'` 就是密码不对，不是数据库没开。别去改 `application.yml` 里的 driver 或 URL，改密码或改启动参数即可。

### 1.3 导入初始化脚本

**必须用 utf8mb4 客户端编码**，否则中文学院名报 `ERROR 1366`：

```bash
cd <ROOT>
mysql --default-character-set=utf8mb4 -uroot -p < db/init.sql
```

脚本会创建 `campus_activity` 库、8 张表、活动类型字典（5 类）、学院字典（7 个）。默认管理员不在这里，由后端首次启动时创建。

验证：

```bash
mysql --default-character-set=utf8mb4 -uroot -p -e "USE campus_activity; SHOW TABLES; SELECT COUNT(*) FROM t_activity_type; SELECT COUNT(*) FROM t_college;"
```

### 1.4 调整 SQL 模式（统计接口需要）

MySQL 8 默认 `ONLY_FULL_GROUP_BY`，统计接口会返回 50000。二选一：

```sql
-- 临时（重启 MySQL 后失效，下次要再执行一遍）
SET GLOBAL sql_mode='STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION';
```

或者写进 `my.cnf` / `my.ini` 的 `[mysqld]` 段，永久生效：

```ini
sql_mode=STRICT_TRANS_TABLES,NO_ZERO_IN_DATE,NO_ZERO_DATE,ERROR_FOR_DIVISION_BY_ZERO,NO_ENGINE_SUBSTITUTION
```

改完重启 MySQL 服务。仓库里的 `CheckInMapper` 已经把分组表达式改一致，这一步是给旧版本兜底。

## 2. 启动后端

### 2.1 修改数据库账号密码

打开 `backend/src/main/resources/application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/campus_activity?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: root
    password: root          # ← 改成你的本机密码
```

注意 `characterEncoding=UTF-8`，**不能写 `utf8mb4`**，Java 不认这个名字，启动会报 `Unsupported character encoding 'utf8mb4'`。

也可以用启动参数覆盖，不改文件：

```bash
--spring.datasource.password=<你的密码>
--spring.datasource.url="jdbc:mysql://127.0.0.1:3306/campus_activity?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false"
```

### 2.2 打包

```bash
cd <ROOT>/backend
mvn -DskipTests clean package
```

产物 `backend/target/activity-system-1.0.0.jar`。编译目标 Java 17，用 JDK 25 也能跑。

如果只想跑源码不打包：

```bash
mvn spring-boot:run
```

### 2.3 启动

```bash
cd <ROOT>/backend
java -jar target/activity-system-1.0.0.jar
```

看到 `Started ActivityApplication` 且没有异常即成功。首次启动 `DataInitializer` 会建默认超管 `admin / admin123`。

需要手机访问时，二维码地址必须指向局域网可达的地址，加一个启动参数：

```bash
java -jar target/activity-system-1.0.0.jar --campus.mobile.base-url=http://<你的局域网IP>/m
```

`<你的局域网IP>` 用 `ipconfig` 查（形如 `192.168.x.x`）。**不要写 localhost**，手机扫开 localhost 指的是手机自己。

### 2.4 验证后端

```bash
curl --noproxy '*' http://localhost:8080/dict/activity-type
curl --noproxy '*' -X POST http://localhost:8080/auth/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
```

第一条返回活动类型列表，第二条返回 token。`curl` 卡住或返回 000 是本机 HTTP 代理捣乱，`--noproxy '*'` 必须加。

不带 token 访问 `http://localhost:8080/admin/current` 应返回 401；带上 `Authorization: Bearer <token>` 应返回管理员信息。这一步能过，说明拦截器工作正常。

### 2.5 Windows 一键脚本

`backend/start-backend.cmd` 会在启动前设置 `sql_mode`，再拉起 jar。用法：

```cmd
set DB_PASSWORD=<你的密码>
cd <ROOT>\backend
start-backend.cmd
```

日志写到 `backend/run-backend.log`。脚本里的 MySQL 路径默认用系统 `mysql` 命令，如果不在 PATH，设置 `MYSQL_BIN` 环境变量指向 `mysql.exe` 的完整路径。

## 3. 启动前端

```bash
cd <ROOT>/frontend
npm ci
npm run dev -- --host 0.0.0.0 --port 5173
```

`--host 0.0.0.0` 是为了让手机/局域网能访问；只在本机测可以省略。`npm ci` 按 `package-lock.json` 安装，不要换成 `npm install`，避免依赖漂移。

看到 `Local: http://localhost:5173/` 和 `Network: http://192.168.x.x:5173/` 即成功。

`frontend/start-frontend.cmd` 是等价的 Windows 脚本（`npm run dev -- --host 0.0.0.0 --port 5173`），日志写 `frontend/run-frontend.log`。

### 3.1 代理为什么这么配

`frontend/vite.config.js` 把 `/api/v1/xxx` 改写成 `/xxx` 再转发到 8080，因为后端以**根路径**部署（`context-path: /`）。前端 `axios` 的 `baseURL` 是 `/api/v1`。别只改其中一处：

- 去掉 rewrite → 后端收到 `/api/v1/...` → 404；
- 把后端改回 `context-path: /api/v1` 却不改 rewrite → 404 且鉴权判断错位。

生产环境同理，`deploy/nginx.conf` 用 `proxy_pass http://127.0.0.1:8080/;`（结尾斜杠）剥掉前缀。

## 4. 登录与后台主链路

打开 `http://localhost:5173`，用 `admin / admin123` 登录。每一步都写清楚 UI 路径、背后接口和期望结果：

| 步 | UI 操作 | 接口 | 期望 |
| --- | --- | --- | --- |
| 1 | 登录页输入账号密码 | `POST /auth/login` | 跳到活动列表，localStorage 有 token |
| 2 | 侧栏「活动管理」→「新建活动」 | `GET /dict/activity-type` | 下拉能选活动类型 |
| 3 | 填标题、类型、介绍、地点、开始/结束时间、报名截止时间、名额 → 保存 | `POST /admin/activity` | 返回 activityId 与 signupGuid，回到列表能看到新活动 |
| 4 | 列表点「发布」 | `POST /admin/activity/{id}/publish` | 状态变为已发布 |
| 5 | 点活动名进详情 | `GET /admin/activity/{id}` | 显示详情与附件 |
| 6 | 详情里查看报名二维码 | `GET /admin/activity/{id}/qrcode` | 出现二维码，内容是 `<base-url>/signup/{guid}` |
| 7 | 手机扫码 → 宣传页 →「立即报名」 | `GET /promo/{guid}` → `POST /signup` | 填姓名、手机号、学院，提交成功 |
| 8 | 后台「报名名单」 | `GET /admin/activity/{id}/registrations` | 看到刚才的报名，手机号默认脱敏 |
| 9 | 「导出名单」 | `GET /admin/activity/{id}/registrations/export` | 下载 xlsx，Excel 能打开 |
| 10 | 「签到记录」→「导出」 | `.../checkins/export` | 下载 xlsx |
| 11 | 侧栏「数据统计」 | `GET /admin/statistics/overview` | 活动数、报名人次、签到率、趋势图有数据 |

第 3 步的时间字段要填完整 `yyyy-MM-dd HH:mm:ss`，别只填日期。第 7 步如果二维码扫不开，多半是 `campus.mobile.base-url` 还是 localhost，回第 2.3 节改。

## 5. 签到演示

新活动默认不能签到。演示前执行（`activity_id` 换成实际 ID）：

```sql
USE campus_activity;
UPDATE t_activity SET
  checkin_enabled = 1,
  signup_deadline = DATE_SUB(NOW(), INTERVAL 30 MINUTE),
  start_time = DATE_SUB(NOW(), INTERVAL 10 MINUTE),
  end_time = DATE_ADD(NOW(), INTERVAL 3 HOUR),
  status = 'ONGOING'
WHERE activity_id = 1;
```

或者用 `deploy/demo-checkin.sql`（同样把 ID 换成实际值）。

然后：

1. 后台打开「签到大屏」→ 路由 `/m/board/{activityId}`，接口 `GET /checkin/qrcode/{activityId}`，每 30 秒刷新一次动态码；
2. 手机扫码进入 `/m/checkin/{activityId}`，提交 `POST /checkin`；
3. 后台「签到记录」能看到记录，`GET /admin/activity/{id}/checkins`；
4. 统计页刷新，签到率变化。

**准确签到在 HTTP 下用不了**：浏览器只在 HTTPS 或 localhost 的安全上下文里给 `navigator.geolocation`。用局域网 IP + HTTP 打开 H5 时，请走不带 `?code=` 的基本签到（不会校验定位与动态码），或者按 `docs/03-服务器部署.md` 配 HTTPS 后再演示准确签到。这点别在答辩现场踩。

## 6. 数据重置

清空业务数据、保留字典与管理员：

```sql
USE campus_activity;
DELETE FROM t_checkin;
DELETE FROM t_registration;
DELETE FROM t_attachment;
DELETE FROM t_activity;
UPDATE t_activity SET signed_count = 0;
```

顺序不能反，先删子表再删主表。想完全从零开始，直接重跑 `db/init.sql`（会删库重建，先备份）。

## 7. 保持服务常驻

三个进程要一直开着：MySQL 服务、java 进程、Vite 进程。关掉终端窗口会中断前后端，测试期间别关。

查看端口与进程：

```bash
netstat -ano | findstr ":3306 :8080 :5173"
tasklist | findstr "java.exe node.exe mysqld.exe"
```

需要停止时（**测试完再做**）：

```bash
taskkill /PID <PID> /F
```

## 8. 排错速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Unsupported character encoding 'utf8mb4'` | JDBC URL 的 charset 名非法 | 改 `characterEncoding=UTF-8` 或启动参数覆盖 |
| `Access denied for user 'root'@'localhost'` | 数据库密码不对 | 确认密码，用 `--spring.datasource.password=` 覆盖 |
| 导入 SQL `ERROR 1366` | 客户端默认 GBK | 加 `--default-character-set=utf8mb4` |
| `curl` 返回 000 / 超时 | 环境变量 HTTP 代理拦截 localhost | `curl --noproxy '*'` |
| 登录成功但所有后台请求 401 | 拦截器路径判断或 token 没带上 | 检查 `LoginInterceptor.normalizePath` 与 axios 请求拦截 |
| 后台接口全部 404 | Vite rewrite 与后端 context-path 不匹配 | 后端保持根路径，rewrite 去掉 `/api/v1` |
| 建活动 500 | 时间格式解析失败 | 用 `yyyy-MM-dd HH:mm:ss`；源码已修 `parseTime` |
| 列表 `data: null` | 重编译漏 `-parameters` | 用 Maven 正常打包，别手工 javac 替换 class |
| 统计接口 50000 | `ONLY_FULL_GROUP_BY` | 第 1.4 节改 `sql_mode` |
| `/admin/current` NPE | 请求没走鉴权，`AdminContext` 为空 | 同「401」条目 |
| 二维码扫开是 `localhost` | `campus.mobile.base-url` 没改 | 启动参数改成局域网/公网地址 |
| 手机打不开页面 | 前端没监听 `0.0.0.0` 或防火墙拦了 | `npm run dev -- --host 0.0.0.0`，放行 5173 |
| 准确签到定位失败 | HTTP 非安全上下文 | 用基本签到，或配 HTTPS |
| 报名被限流误拦 | 反代后所有 IP 都是 127.0.0.1 | 生产配置里开 `RemoteIpValve`，或调大 `ip-limit-per-minute` |
