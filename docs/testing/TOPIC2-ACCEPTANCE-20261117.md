# 题目二对齐与完整验收

验收日期：2026-11-17（Asia/Shanghai）。依据用户提供截图中的“高校学生活动全流程管理系统”。结论：本机验收范围内，必做功能均已覆盖；直播/附件、组合筛选、报名时效和基本/准确签到选做能力已实现。国产数据库为题目选做项，本项目继续使用MySQL8，未宣称已适配达梦。当前没有服务器，未进行公网HTTPS、真实手机定位或生产容量验收。

## 本次修正

- 移除审批状态和已发布状态对编辑的限制。未发布、报名中、截止、进行中、结束及内部取消状态均经过编辑/删除接口检查。
- 编辑在同一事务中更新内容并撤销待审旧申请；已发布内容可直接修改。历史审批快照保留，旧申请不能批准新内容。报名/签到记录、原宣传链接和已发布的时间保持，修改活动时间后立即更新生命周期状态。
- 活动列表补充发布时间。删除按钮及确认框统一为“删除活动”，采用逻辑删除，报名/签到停止，历史数据保留。
- 修复编辑页加载竞态：资料加载完成前不显示可编辑表单，失败可重试，防止旧响应覆盖用户刚输入的标题。浏览器测试实际复现过该问题，修复后验证保存成功。
