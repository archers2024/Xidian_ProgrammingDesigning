# 06 - 别人拿到这个项目怎么运行

## 先分清三种情况

| 你的目的 | 该怎么做 |
| --- | --- |
| 只想看看效果，不想装环境 | 不用跑，看截图/录屏；或让对方在自己机器上跑起来，你连同一 WiFi 访问 |
| 交作业、验收、要改代码 | 本文「三步跑起来」 |
| 挂到服务器让别人访问 | 见 `03-服务器部署.md` |

## 环境要求

| 组件 | 版本 | 检查命令 | 没装去哪下 |
| --- | --- | --- | --- |
| JDK | **17 或更高** | `java -version` | https://adoptium.net/temurin/releases/?version=17 |
| MySQL | 8.0.x | `mysql --version` | https://dev.mysql.com/downloads/installer/ |
| Node.js | **18 或更高** | `node -v` | https://nodejs.org/zh-cn/download |
| Maven | 3.8+ | `mvn -v` | **不用装**，仓库自带 `mvnw` |

> 装完记得重开一个命令行窗口，PATH 才生效。脚本会自己探测安装位置，不需要手工配环境变量。

## 三步跑起来

### 第 1 步：拿代码

```bash
git clone https://github.com/archers2024/Xidian_ProgrammingDesigning.git
cd Xidian_ProgrammingDesigning
```

或者网页上 `Code → Download ZIP` 解压。

**路径必须是纯英文。** `D:\campus-activity\` 可以，`D:\我的项目\` 不行——mysqld 解析含中文的 `--datadir` 会截断路径并报 `Failed to set datadir (OS errno: 2)`。

### 第 2 步：首次安装（只跑一次）

双击 **`首次安装.cmd`**（英文名 `install.cmd`）：

- 自动探测 JDK，编译后端 `activity-system-1.0.0.jar`（首次 2–5 分钟，要下依赖）
- 安装前端依赖（约 210MB，2–5 分钟）
- 没装 Maven 也行，脚本用仓库自带的 `mvnw.cmd`

仓库不提交 `backend/target`（编译产物）和 `frontend/node_modules`（太大），所以这一步不能跳。

### 第 3 步：准备数据库（二选一）

**A. 本机已经有 MySQL 服务**（用 Installer 装过的人一般是这种）

```cmd
:: 确认服务在跑
net start MySQL80

:: 导入快照（含 2 个活动、1 条报名、1 条签到）
mysql --default-character-set=utf8mb4 -uroot -p < db\campus_activity_dump.sql
```

然后把 `scripts\start-all.ps1` 顶部的 `$DbPass` 改成**你自己的 root 密码**（默认写的是 `123456`）。

**B. 没有 MySQL 服务**

双击 **`初始化数据库.cmd`**（`init-db.cmd`）。它会：

1. 在 `db\data` 建独立 MySQL 实例（不动系统里的 MySQL）
2. 设置 root 密码为 `123456`
3. 导入 `db\campus_activity_dump.sql`
4. 关闭临时实例，约 30 秒

不用装 MySQL 服务，也不用改任何配置。

### 第 4 步：启动

双击 **`启动全部.cmd`**（`start-all.cmd`）。脚本依次拉起 MySQL → 后端 → 前端，末尾打印地址：

```
电脑端    http://localhost:5173        账号 admin / admin123
手机端    http://192.168.31.184:5173/m
后端 API  http://192.168.31.184:8080
```

手机端地址里的 IP 是脚本按默认路由自动取的，换 WiFi 会跟着变。

停止服务：双击 `停止全部.cmd`。**关掉命令行窗口不会停服务**，数据也不会丢。

## 手工启动（不想用脚本）

```bash
# 后端（先导入 SQL，并确认 MySQL 在 3306）
cd backend
mvnw.cmd -DskipTests package          # 或 mvn -DskipTests package
java -jar target\activity-system-1.0.0.jar --spring.datasource.password=你的密码

# 前端（另开一个窗口）
cd frontend
npm ci
npm run dev -- --host 0.0.0.0 --port 5173
```

后端直连不带 `/api/v1`，前缀由 Vite 代理剥离；这一点改了要同步改 `vite.config.js` 和 `deploy/nginx.conf`。

## 常见错误对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Failed to set datadir ... OS errno: 2` | 项目路径含中文 | 挪到纯英文路径 |
| `Access denied for user 'root'@'localhost'` | 数据库密码不对 | 改 `scripts\start-all.ps1` 的 `$DbPass` |
| `Unknown database 'campus_activity'` | 没导入 SQL | 按第 3 步导入 `campus_activity_dump.sql` |
| `Port 8080 was already in use` | 8080 被别的程序占着 | `netstat -ano \| findstr :8080` 找到 PID 后结束它 |
| 页面白屏、接口 404 | 前端没起来或代理没生效 | 看 `logs\frontend.log`、`logs\backend.log` |
| `UnsupportedClassVersionError` | JDK 低于 17 | 装 JDK 17+，或删掉 `backend\target` 后重跑首次安装 |
| 统计页报 `code: 50000` | MySQL 的 `sql_mode` 含 `ONLY_FULL_GROUP_BY` | 重跑 `启动全部.cmd`，脚本会自动修正 |
| `npm ci` 卡住 / 报网络错 | 默认源太慢 | `npm config set registry https://registry.npmmirror.com` 后重试 |
| `mvnw` 首次运行很慢 | 要下 Maven 发行版（约 10MB）+ 依赖 | 正常，只有第一次 |

## 只想给对方看效果

不用让对方装环境，三种办法：

1. **同一 WiFi**：你这边跑着，对方浏览器打开 `http://<你的局域网IP>:5173`。注意对方能改数据，账号也是共用的。
2. **内网穿透**：cpolar / natapp 之类把 5173 映射到公网，发临时链接。
3. **录屏 / 截图**：最省事，也不会有数据被改的风险。

## 验收要看什么

1. 登录 `admin / admin123` → 活动列表有 2 条
2. 新建活动 → 发布 → 详情页看二维码
3. 手机扫码进宣传页 → 报名（手机号必须 11 位）
4. 后台报名名单：手机号默认脱敏为 `139****1234`，超级管理员可切换查看原号
5. 活动详情开关签到 → 手机扫码签到
6. 签到记录 + 导出 Excel
7. 统计页：活动数、报名人次、签到率、趋势图
